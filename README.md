## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env.local
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.

### 4. Build for Production
```bash
npm run build
npm run start
```

## Deployment on Vercel

This repository is optimized for one-click deployment on [Vercel](https://vercel.com):

1. Import this repository in your Vercel Dashboard.
2. Next.js preset will be automatically detected.
3. Configure optional environment variables (from `.env.example`).
4. Click **Deploy**.
